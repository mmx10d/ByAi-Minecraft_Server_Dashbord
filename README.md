# 🎮 نظام الإدارة السحابي المستقل لسيرفرات ماين كرافت (Ultimate Modular Minecraft Wrapper)

نظام هندسي متكامل ومتقدم مبني بلغة **Node.js**، يعتمد على بنية برمجية منفصلة تماماً (**Decoupled Architecture**). يتميز النظام بفصل النواة الخلفية (Backend Core) عن واجهات التحكم الخارجية (Clients/Frontend)، ويتيح إدارة سيرفر ماين كرافت جافا (`paper.jar`) والتحكم الكامل به عن بعد حياً عبر بروتوكول الـ **WebSockets**، مع دعم تقنية "النوم الذكي" الفائقة لحفظ موارد الجهاز 100%.

---

## 💎 المميزات الخارقة للنظام (Aternos-Like & Beyond)

1. **بنية مستقلة بالكامل (100% Flexible & Decoupled):** واجهات الويب والبوتات تعمل بشكل منفصل تماماً؛ يمكنك تشغيلها، إغلاقها، أو تطويرها دون التأثير على استقرار اللعبة وسيرفر الجافا.
2. **نظام النوم والتشغيل الذاتي عند الطلب (Smart Wake-on-Demand):** في حال خلو السيرفر من اللاعبين لمدة 5 دقائق، يقوم النظام تلقائياً بإطفاء سيرفر ماين كرافت الثقيل لحفظ الرام والمعالج، ويشغل مكانه "سيرفر وهمي خفيف جداً". بمجرد محاولة أي لاعب الدخول، يستشعر النظام الاتصال، ويقوم بإيقاظ وتشغيل السيرفر الحقيقي فوراً!
3. **الموافقة التلقائية على الشروط (Auto-EULA Acceptance):** يتولى النظام قراءة وإنشاء ملف `eula.txt` والموافقة على الشروط برمجياً لضمان عدم تعليق السيرفر عند الإقلاع الأول.
4. **بث السجلات الحي وتلوينها الذكي (Real-time Log Streamer):** يتم التقاط مخرجات كونسل ماين كرافت (stdout/stderr) وتغليفها برمجياً في حزم JSON، ثم بثها فوراً لكافة الكلاينتس مع تلوين ذكي للـ الأخطاء (Errors) والتحذيرات (Warnings).
5. **مراقبة الموارد الحية (Live Resource Monitoring):** قراءة حية ومباشرة لنسب استهلاك المعالج (CPU) والذاكرة العشوائية (RAM) الخاصة بجهاز الاستضافة عبر عمليات رياضية برمجية دقيقة تعتمد على الـ OS.

## 📂 خريطة الهيكل المعماري للمشروع (Directory Structure)

```text
├── commands/            # ⚙️ النواة والمنطق البرمجي (Backend Core Logics)
│   ├── backup.js        # نظام النسخ الاحتياطي التلقائي والمجدول للعوالم
│   ├── host.js          # قراءة بيئة نظام التشغيل وموارد الجهاز الحية (RAM/CPU)
│   ├── information.js   # محلل ومستمع الكونسل لرصد دخول وخروج اللاعبين والحالة الحية
│   ├── player.js        # معالج أوامر اللاعبين الصارمة (حظر بالاسم، حظر آي بي، طرد مسبب)
│   ├── plugins.js       # محرك تفعيل، جلب، وحذف الإضافات والمودات برمجياً
│   ├── scheduler.js     # محرك النوم الذكي وخادم الـ Proxy الخفيف للإيقاظ التلقائي
│   ├── server.js        # منشئ عملية الجافا الأساسية (Process Spawn) والـ Log Listener
│   └── world.js         # محرر ملف server.properties (المود، الحد الأقصى، السماح بالمكرك)
├── web/                 # 🖥️ واجهة الويب التحكمية الاحترافية (Standalone Frontend)
│   ├── index.html       # الهيكل البنائي النظيف والمتطور للوحة التحكم
│   ├── style.css        # التصميم البصري والألوان الحصرية النيونية (Dark Cyberpunk Theme)
│   └── script.js        # محرك السوكيت المستقل لإدارة الأحداث وجلب الموارد كل 5 ثوانٍ
├── clients/             # 🤖 واجهات البوتات والقنوات الخارجية المستقلة
│   ├── discordBot.js    # بوت بث الكونسل حياً والتحكم بالأوامر من شات ديسكورد
│   └── telegramBot.js   # بوت الإدارة والمراقبة المحمول المؤمن للأدمن فقط عبر تلجرام
├── .env                 # 🔐 ملف تكوين البيئة وحفظ الرموز السرية والـ Tokens للمستخدم
├── index.js             # 🚀 المايسترو المحرك ومطلق خادم السوكيت المركزي (Port: 8080)
├── minecraft.js         # 📦 المجمع البرمجي المركزي (Central API Export) لربط كافة الملفات
└── paper.jar            # 🎮 ملف تشغيل سيرفر ماين كرافت الفعلي (Java Executable)
```

## 🛠️ دليل التجهيز والتشغيل للمرة الأولى

### 1. تثبيت البيئة والمكتبات المطلوبة
يجب أن يكون لديك **Node.js** و **Java** مثبتين على جهازك. افتح موجه الأوامر (CMD / Terminal) في المجلد الرئيسي للمشروع وشغل الأمر التالي لتثبيت الحزم الصارمة:
```bash
npm install ws discord.js telegraf dotenv minecraft-protocol
```

### 2. تهيئة ملف الرموز السرية (`.env`)
أنشئ أو افتح ملف باسم `.env` في جذر المشروع الرئيسي، وقم بتعبئة بياناتك الخاصة بدقة:
```env
# رابط السوكيت المركزي للنظام
SOCKET_URL=ws://localhost:8080

# إعدادات بوت ديسكورد
DISCORD_TOKEN=MTB0Nj... (ضع توكن البوت الخاص بك هنا)
DISCORD_CHANNEL_ID=123456789... (آيدي الروم النصية التي سيعرض فيها الكونسل)

# إعدادات بوت تلجرام
TELEGRAM_TOKEN=123456:AAFi... (ضع توكن بوت تلجرام الخاص بك هنا)
TELEGRAM_ADMIN_ID=987654321 (آيدي حسابك الشخصي في تلجرام لمنع الآخرين من التحكم)
```

### 3. إطلاق النواة والخادم الخلفي
من المجلد الرئيسي للمشروع، قم بتشغيل المنظومة المركزية عبر الأمر التالي:
```bash
node index.js
```
*بمجرد التشغيل: سيقوم النظام بفحص الـ Eula والموافقة عليها، تشغيل خادم السوكيت على البورت 8080، وبدء قذف عملية الجافا لسيرفر ماين كرافت فوراً.*

## 🕹️ تشغيل وإدارة واجهات التحكم المستقلة (Clients)

يمكنك تشغيل أي واجهة من الواجهات التالية بشكل مستقل تماماً وفي أي وقت:

### 🌐 أولاً: لوحة الويب الاحترافية المتطورة (`web/`)
لا تحتاج إلى أي خادم محلي لتشغيلها! نظراً لاستقلاليتها الكاملة، ما عليك سوى الانتقال لمجلد `web` والضغط مرتين على ملف `index.html` ليفتح في متصفحك (Chrome / Edge / Firefox). 
* ستقوم الصفحة تلقائياً بالربط بالسوكيت الخلفي، وعرض الرسوم البيانية، ونسب الرام والمعالج، وبث مخرجات الكونسل مع إمكانية كتابة الأوامر مباشرة من المتصفح.

### 👾 ثانياً: بوت ديسكورد (`clients/discordBot.js`)
لتشغيل البوت وجعله متصلاً، افتح نافذة Terminal جديدة وشغل الأمر التالي:
```bash
cd clients
node discordBot.js
```
* **الأوامر المتاحة في الشات:**
  * كتابة أي نص عادي (مثل `say Welcome to Server`) سيتم تمريرها فوراً كأمر كونسل داخل اللعبة.
  * كتابة `!restart` لإعادة تشغيل النظام برمجياً بكفاءة.
  * كتابة `!status` لجلب تقرير سريع عن الموارد الحية.

### 📢 ثالثاً: بوت تلجرام لغرفة العمليات المحمولة (`clients/telegramBot.js`)
لتفعيل التحكم من هاتفك الذكي من أي مكان في العالم، افتح نافذة Terminal منفصلة وشغل:
```bash
cd clients
node telegramBot.js
```
* **الأوامر المتاحة للأدمن فقط:**
  * `/start` - إيقاظ وتشغيل سيرفر ماين كرافت برمجياً.
  * `/stop` - إرسال أمر إغلاق آمن وحفظ بيانات اللاعبين والعالم.
  * `/status` - سحب تقرير فوري مشفر عن نسب الرام، المعالج، وحالة السيرفر وعدد اللاعبين أونلاين.
  * إرسال أي رسالة نصية عادية للبوت سيقوم الكور بتنفيذها كأمر كونسل مباشر (مثل `op MyUsername`).

## 📡 دليل بروتوكول حزم البيانات الموحد (WebSocket JSON API Reference)

إذا كنت مطوراً وترغب في ربط هذا السيرفر بتطبيق مخصص من بنائك (مثل لوحة تحكم بـ **React**, **Vue** أو تطبيق هواتف بـ **Flutter**)، يمكنك الاتصال بـ `ws://localhost:8080` وتبادل حزم البيانات بالتنسيق القياسي التالي:

### 1. الحزم الصادرة من الكلاينت إلى السيرفر (Client Requests)

| الإجراء (Action) | الحزمة الممررة (Payload) | الوظيفة البرمجية |
| :--- | :--- | :--- |
| `START_SERVER` | لا يوجد | تشغيل وإقلاع عملية ماين كرافت فوراً |
| `STOP_SERVER` | لا يوجد | إيقاف آمن للسيرفر وحفظ بيانات العالم الخارجي |
| `RESTART_SERVER` | لا يوجد | إعادة تشغيل ذكية آمنة تمنع تداخل المنافذ |
| `GET_HOST_STATS` | لا يوجد | طلب فوري لتقرير استهلاك الرام والمعالج والحالة الحية |
| `MINECRAFT_COMMAND` | `{ "command": "الأمر هنا" }` | تنفيذ أمر كونسل مباشر داخل اللعبة (مثل `kick`, `op`) |

### 2. الحزم الواردة من السيرفر إلى الكلاينت (Server Responses)

* **حزمة السجلات الحية (Log Broadcast):**
```json
{
  "type": "LOG",
  "data": "[14:22:15 INFO]: Done (4.125s)! For help, type \"help\""
}
```

* **حزمة الموارد الحية (Host Resource Stats):**
```json
{
  "type": "HOST_STATS",
  "data": {
    "status": "ONLINE",
    "ram": "42.15%",
    "cpu": "12.50%",
    "playersCount": 3
  }
}
```

* **حزمة الترحيب والاتصال المنظومي (System Welcome):**
```json
{
  "type": "SYSTEM",
  "data": "Connected Successfully to Core Backend"
}
```
