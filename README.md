# 🎮 Project Minecraft Server Wrapper (Node.js)

نظام احترافي مبني بلغة **Node.js** لإدارة، تشغيل، والتحكم بسيرفرات ماين كرافت جافا (`paper.jar`) برمجياً عبر الـ Modules وعن بعد بواسطة **WebSockets**.

## ✨ الميزات الأساسية
- **AcceptEula التلقائي**: يقوم النظام بالموافقة على شروط الـ EULA برمجياً دون تدخل يدوي.
- **WebSocket Control**: إمكانية إرسال الأوامر واستقبال مخرجات السيرفر حياً عبر السوكيت من كونسل خارجي أو لوحة ويب.
- **Modular Structure**: تقسيم ذكي ومنظم للملفات لسهولة التعديل والتطوير.

---

## 🛠️ طريقة التشغيل
1. تأكد من وجود ملف السيرفر باسم `paper.jar` في المجلد الرئيسي.
2. قم بتثبيت الحزم المطلوبة عبر الـ Terminal:
   ```bash
   npm install
   ```
3. شغل نظام التحكم الأساسي:
   ```bash
   node index.js
   ```

## 📂 خريطة الدوال البرمجية (API Reference)

يمكنك استدعاء هذه الدوال من أي مكان داخل مشروعك عبر استيراد موديول `minecraft.js`:

### 1. إدارة النظام العام (`minecraft.server`)
- `startServer()`: بدء تشغيل السيرفر وعمل الـ Spawn للجافا.
- `stopServer()`: إرسال أمر إيقاف آمن وحفظ العالم.
- `restartServer()`: إعادة تشغيل ذكية تنتظر إغلاق المنفذ لتفادي تعليق السيرفر.
- `acceptEula()`: الموافقة التلقائية والكتابة على ملف الشروط.

### 2. التحكم باللاعبين (`minecraft.player`)
- `bannedPlayer(playerName)`: حظر لاعب من الدخول باستخدام اسمه.
- `bannedIp(playerName)`: حظر رقم الآي بي الخاص باللاعب بشكل دائم.
- `kickPlayer(playerName, reason)`: طرد لاعب حالي مع كتابة رسالة توضيحية تظهر له.

### 3. إعدادات وتكوين العالم (`minecraft.world`)
- `setMaxPlayers(count)`: تحديد الحد الأقصى المسموح به للاعبين في ملف الخصائص.
- `changeGamemode(mode)`: تغيير الجيم مود الافتراضي فورا حياً (survival, creative, إلخ).
- `setCrackAllowed(true/false)`: السماح بدخول أصحاب النسخ المكركة أو قصر السيرفر على الحسابات الأصلية.
- `deleteWorld()`: مسح خريطة السيرفر بالكامل بآمان (يتطلب إطفاء السيرفر).

### 4. معلومات وموارد الخادم الحية (`minecraft.info` & `minecraft.host`)
- `getServerStatus()`: يعود بحالة السيرفر (`ONLINE` / `OFFLINE`).
- `getOnlinePlayersList()`: مصفوفة حية بأسماء جميع اللاعبين المتواجدين داخل السيرفر حالياً.
- `getRamUsage()` / `getCpuUsage()`: قراءة نسب استهلاك موارد جهاز الاستضافة بدقة.
