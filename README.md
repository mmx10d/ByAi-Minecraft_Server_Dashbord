# 🎮 نظام إدارة سيرفرات ماين كرافت المرن (Multi-Client Wrapper)

نظام متكامل مبني بلغة **Node.js** يفصل النواة الخلفية (Backend Logics) تماماً عن واجهات التحكم (Clients). يتيح لك التحكم الكامل بسيرفر ماين كرافت جافا عبر لوحات الويب، ديسكورد، وتلجرام في نفس الوقت حياً عبر تقنية الـ WebSockets.

## 📂 هيكلية المجلدات الحالية
```text
├── commands/            # مجلد الدوال والمنطق البرمجي الخاص بالسيرفر
│   ├── host.js          # قراءة موارد الجهاز والمضيف
│   ├── information.js   # رصد وتحليل مخرجات اللاعبين والحالة
│   ├── player.js        # أوامر حظر وطرد اللاعبين
│   ├── server.js        # النواة وتشغيل الـ jar والموافقة التلقائية على الـ Eula
│   └── world.js         # إعدادات المود والعالم والحد الأقصى
├── clients/             # مجلد الواجهات الخارجية والكلاينتس
│   ├── discordBot.js    # بوت التحكم وقراءة السجلات من ديسكورد
│   ├── telegramBot.js   # بوت الإدارة وفحص الموارد من تلجرام
│   └── webConsole.html  # واجهة المتصفح الحية للأزرار والكونسل
├── .env                 # ملف إدخال الـ Tokens السرية (يعدله المستخدم)
├── index.js             # المايسترو المحرك لخادم السوكيت المركزي والسيرفر
├── minecraft.js         # المجمع الرئيسي لتصدير الدوال والميزات
└── paper.jar            # ملف تشغيل سيرفر ماين كرافت الفعلي
```

---

## 🚀 طريقة التجهيز والتشغيل للمستخدم

### الخطوة 1: تهيئة التوكنات
افتح ملف `.env` المتواجد في المجلد الرئيسي، وقم بوضع الرموز الخاصة بك (Tokens و IDs) ثم احفظ الملف.

### الخطوة 2: تشغيل الخادم المركزي
من المجلد الرئيسي للمشروع، قم بتشغيل المنظومة والنواة الأساسية:
```bash
node index.js
```

### الخطوة 3: تشغيل الواجهات (Clients)
يمكنك تشغيل أي واجهة بشكل مستقل في Terminal منفصل دون أن تؤثر على الأخرى:

- **لتشغيل بوت ديسكورد:**
  ```bash
  cd clients
  node discordBot.js
  ```
- **لتشغيل بوت تلجرام:**
  ```bash
  cd clients
  node telegramBot.js
  ```
- **لتشغيل واجهة الويب:**
  فقط قم بفتح ملف `webConsole.html` داخل مجلد `clients` في متصفح كروم أو فايرفوكس واستمتع بالتحكم التلقائي الفوري!

## 📡 بروتوكول حزم البيانات الموحد (JSON Socket API)
إذا أردت بناء تطبيق إضافي أو واجهة جديدة بـ React أو Flutter، تواصل مع السوكيت `ws://localhost:8080` وأرسل البيانات بالصيغة التالية:
```json
{
  "action": "START_SERVER | STOP_SERVER | RESTART_SERVER | GET_HOST_STATS",
  "payload": { "command": "أمر ماين كرافت", "mode": "وضع اللعب" }
}
```
