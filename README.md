# 🎮 نظام الإدارة السحابي المتكامل لسيرفرات ماين كرافت (Ultimate Standalone Minecraft Wrapper)

نظام برمجى متقدم ومكتمل مبني بالكامل على منصة **Node.js**، يعتمد على معمارية فصل المهام التامة (**Decoupled Architecture**). يقوم النظام بفصل النواة الخلفية (Backend Core) عن واجهات التحكم الأمامية (Clients/Frontend)، ويتيح لك التحكم المطلق وإدارة سيرفر ماين كرافت جافا (`paper.jar`) حياً وعن بعد عبر بروتوكول الـ **WebSockets**، مع دعم تقنية "النوم والإنصات الذكي" الفريدة لحفظ موارد جهاز الاستضافة بنسبة 100%.

---

## 💎 العبقرية البرمجية والمميزات الخارقة (Core Features)

1. **المرونة المطلقة والفصل التام (100% Independent Components):** واجهات الويب وبوتات التحكم تعمل بشكل مستقل تماماً كأدوات "كلاينت" منفصلة. يمكنك إغلاقها، تشغيلها، أو رفعها على استضافات خارجية دون أن يتأثر سيرفر الجافا أو خط اتصال اللاعبين إطلاقاً.
2. **نظام النوم والتشغيل الذاتي عند الطلب (Smart Wake-on-Demand):** الميزة الأقوى في المشروع! في حال خلو السيرفر من اللاعبين لمدة 5 دقائق، يقوم النظام تلقائياً بإغلاق سيرفر ماين كرافت الثقيل لتحرير الرام والمعالج تماماً، ويشغل مكانه "خادم وهمي خفيف جداً (Proxy)". بمجرد محاولة أي لاعب الدخول، يلقط النظام الاتصال ويقوم بإيقاظ وتشغيل السيرفر الحقيقي فوراً وطرده برسالة ترحيبية مهذبة ليعيد الدخول بعد دقيقة!
3. **محلل السجلات حياً بالـ RegEx الصارم (Live RegEx Log Analyzer):** تم استبدال آليات التقطيع التقليدية للكونسل بنظام "تعبيرات نمطية" متطور، يستمع لأسطر كونسل ماين كرافت ويلقط دخول وخروج اللاعبين بدقة فائقة مهما اختلف وقت الاستضافة أو إصدار السيرفر.
4. **مراقبة ملفات الـ JSON الحية من القرص (Live JSON Sync):** يقوم النظام بقراءة وتحليل ملفات السيرفر الداخلية مباشرة من الهارد ديسك (`ops.json`, `whitelist.json`, `banned-players.json`, `banned-ips.json`) ليعرض لك القوائم الخمس الحية للاعبين حتى لو كان السيرفر مطفأً أو في وضع النوم!
5. **مراقبة الموارد الحية (Live OS Resource Monitoring):** سحب نسب استهلاك المعالج (CPU) والذاكرة العشوائية (RAM) الحقيقية لجهاز الاستضافة بانتظام كل 5 ثوانٍ عبر مكتبة نظام التشغيل المدمجة.

## 📂 خريطة الهيكل المعماري للمشروع (Directory Tree)

```text
├── commands/            # ⚙️ المنطق البرمجي ونواة النظام (Backend Core Logics)
│   ├── backup.js        # نظام النسخ الاحتياطي التلقائي والمجمد للعوالم
│   ├── host.js          # قراءة بيئة نظام التشغيل وموارد الجهاز الحية (RAM/CPU)

│   ├── plugins.js       # محرك تفعيل، جلب، وحذف الإضافات والـ Plugins برمجياً
│   ├── scheduler.js     # 💤 محرك النوم الذكي وخادم الـ Proxy الخفيف للإيقاظ التلقائي
│   ├── server.js        # منشئ عملية الجافا الأساسية (Process Spawn) وموزع السجلات
│   └── world.js         # محرر خصائص السيرفر (المود، الحد الأقصى، السماح بالمكرك)
├── web/                 # 🖥️ واجهة الويب التحكمية السحابية (Static Frontend)
│   ├── index.html       # الهيكل البنائي النظيف والمتطور لجداول اللوحة
│   ├── style.css        # التصميم البصري والألوان السيبرانية الحصرية (Cyberpunk Dark Mode)
│   └── script.js        # محرك السوكيت المستقل لإدارة الأحداث وبناء الجداول الحية بالنقر
├── clients/             # 🤖 واجهات القنوات والبوتات الخارجية المستقلة
│   ├── discordBot.js    # بوت ديسكورد الاحترافي لبث الكونسل والتحكم بالقوائم المنسدلة
│   └── telegramBot.js   # بوت تلجرام لغرفة العمليات المحمولة بالأزرار التفاعلية للأدمن
├── .env                 # 🔐 ملف تكوين البيئة وحفظ الرموز السرية والـ Tokens للمستخدم
├── index.js             # 🚀 المايسترو المحرك ومطلق خادم السوكيت المركزي (ws://localhost:8080)
├── minecraft.js         # 📦 المجمع البرمجي المركزي (Central API Export) لربط كافة الملفات
└── paper.jar            # 🎮 ملف تشغيل سيرفر ماين كرافت الفعلي (Java Executable)
```

## 🛠️ دليل التجهيز والتثبيت للمرة الأولى

### 1. المتطلبات الأساسية للنظام
تأكد من تنصيب البرمجيات التالية على بيئة الاستضافة لديك:
- **Node.js** (الإصدار 18 أو أحدث)
- **Java Runtime Environment (JRE)** (متوافق مع إصدار نسخة ماين كرافت الخاصة بك)

### 2. تثبيت المكتبات البرمجية الصارمة
افتح موجه الأوامر (CMD / Terminal) في المجلد الرئيسي للمشروع (بجانب ملف `index.js`) وشغل الأمر التالي لتنزيل الحزم المستقرة:
```bash
npm install ws discord.js telegraf dotenv minecraft-protocol
```

### 3. إعداد وضبط ملف المتغيرات والرموز السرية (`.env`)
أنشئ أو افتح ملف باسم `.env` في جذر المشروع الرئيسي، وقم بتعبيئة بياناتك الخاصة بدقة دون ترك مسافات:
```env
# رابط خط السوكيت المركزي للنظام
SOCKET_URL=ws://localhost:8080

# إعدادات كائن بوت ديسكورد
DISCORD_TOKEN=ضع_توكن_البوت_الخاص_بأزرار_ديسكورد_هنا
DISCORD_CHANNEL_ID=ضع_آيدي_الروم_النصية_التي_سيعرض_فيها_الكونسل

# إعدادات كائن بوت تلجرام التفاعلي بالنقر
TELEGRAM_TOKEN=ضع_توكن_بوت_تلجرام_المستخرج_من_بوت_فاذر_هنا
TELEGRAM_ADMIN_USERNAME=يوزر_نيم_حسابك_في_تلجرام_الخاص_بالتحقق_بدون_علامة_@
```

## 🖥️ تشغيل وإدارة واجهات التحكم المستقلة (Clients & Frontend)

نظراً لاعتماد النظام على معمارية فصل المهام، فإن جميع الواجهات مصممة لتعمل بشكل منفصل تماماً عن السيرفر الرئيسي. يمكنك تشغيلها أو إغلاقها في أي وقت دون التأثير على استقرار اللعبة:

### 1. لوحة الويب الاحترافية المتطورة (`web/`)
لا تحتاج إلى أي أمر تشغيل أو خادم محلي! نظراً لاستقلاليتها الكاملة، ما عليك سوى الانتقال لمجلد `web` والضغط مرتين على ملف `index.html` ليفتح في متصفحك.
* ستقوم الصفحة تلقائياً بالربط بالسوكيت الخلفي، وتحديث الجداول الخمسة للاعبين والأدمنية والمحجوبين حياً من القرص، مع توفير أزرار تحكم سريعة وعقوبات فورية بنظام النقر.

### 2. بوت تلجرام لغرفة العمليات المحمولة (`clients/telegramBot.js`)
لتفعيل التحكم الكامل من هاتفك عبر الأزرار التفاعلية (Inline Keyboards)، افتح نافذة Terminal جديدة في جذر المشروع وشغل:
```bash
cd clients
node telegramBot.js
```
* **القوائم المتاحة بالأزرار:**
  * **إدارة اللاعبين أونلاين:** تعرض كل لاعب في زر مستقل لتطبيق الطرد أو الحظر أو الترقية بنقرة واحدة.
  * **الأدمنية والمسؤولين (OP):** سحب رتبة الـ OP فوراً من أي مسؤول عبر القرص.
  * **المحظورين والآي بي:** عرض القوائم السوداء وفك الحظر التلقائي عن الحسابات أو الـ IPs بنقرة زر.
  * **فحص الموارد والصيانة:** سحب تقرير الرام والمعالج حياً، أو عمل نسخة احتياطية مضغوطة (Backup).

### 3. بوت ديسكورد للتحكم السريع وبث الكونسل (`clients/discordBot.js`)
لتشغيل البوت وجعله متصلاً ببوابة الـ WebSocket لبث مخرجات الكونسل الحية، افتح نافذة Terminal منفصلة وشغل:
```bash
cd clients
node discordBot.js
```
* اذهب لـ روم التحكم المخصصة في ديسكورد واكتب كلمة `لوحة` أو `!panel` لتظهر لك اللوحة الرسومية المتطورة المزودة بالقوائم المنسدلة (Select Menus) لإدارة وحظر وفك حظر اللاعبين تفاعلياً.

## 📡 دليل بروتوكول حزم البيانات الموحد (WebSocket JSON API Reference)

إذا كنت مطوراً وترغب في ربط هذا السيرفر بتطبيق مخصص من بنائك (مثل لوحة تحكم بـ **React**, **Vue** أو تطبيق هواتف بـ **Flutter**)، يمكنك الاتصال بـ `ws://localhost:8080` وتبادل حزم البيانات بالتنسيق القياسي التالي:

### 1. الحزم الصادرة من الكلاينت إلى السيرفر (Client Requests)

| الإجراء (Action) | الحزمة الممررة (Payload) | الوظيفة البرمجية |
| :--- | :--- | :--- |
| `START_SERVER` | لا يوجد | تشغيل وإقلاع عملية ماين كرافت فوراً |
| `STOP_SERVER` | لا يوجد | إيقاف آمن للسيرفر وحفظ بيانات العالم الخارجي |
| `RESTART_SERVER` | لا يوجد | إعادة تشغيل ذكية آمنة تمنع تداخل المنافذ |
| `GET_HOST_STATS` | لا يوجد | طلب فوري لتقرير استهلاك الرام والمعالج والقوائم الخمس |
| `MINECRAFT_COMMAND` | `{ "command": "الأمر هنا" }` | تنفيذ أمر كونسل مباشر داخل اللعبة (مثل `kick`, `op`) |

### 2. الحزم الواردة من السيرفر إلى الكلاينت (Server Responses)

* **حزمة السجلات الحية (Log Broadcast):**
```json
{
  "type": "LOG",
  "data": "[18:30:00 INFO]: Done (5.241s)! For help, type \"help\""
}
```

* **حزمة الموارد والقوائم الحية الشاملة (Host Resource & Lists Stats):**
```json
{
  "type": "HOST_STATS",
  "data": {
    "status": "ONLINE",
    "ram": "45.12%",
    "cpu": "10.50%",
    "playersCount": 1,
    "playersOnline": ["Ahmed_User"],
    "opsList": ["Admin_Core"],
    "whitelistList": ["Player_Friend"],
    "bannedPlayersList": ["Spammer_Guy"],
    "bannedIpsList": ["127.0.0.1"]
  }
}
```

## 🛡️ إرشادات الصيانة والأمان

1. **حماية المنفذ 8080:** خادم الـ WebSocket يستمع على البورت `8080` بشكل افتراضي، في حال رفع المشروع على سيرفر خارجي (VPS)، تأكد من إغلاق هذا البورت في جدار الحماية (Firewall) أو تفعيل بروتوكول حماية (Token Auth) لضمان عدم اختراق السيرفر عبر السوكيت.
2. **إصدار ماين كرافت ووضع النوم:** يقوم نظام النوم الذكي بتشغيل Proxy خفيف متوافق افتراضياً مع إصدار `1.20.4` لتمرير رسائل الدخول للاعبين حياً، يمكنك تعديل خيار الـ `version` داخل ملف `commands/scheduler.js` ليطابق إصدار خادمك الخاص تماماً.
3. **سلامة الحفظ والباك اب:** عند النقر على زر النسخ الاحتياطي، يقوم المحرك تلقائياً بضخ أمر `save-all` للسيرفر أولاً لإجبار جافا على كتابة كافة البيانات المتبقية في الذاكرة على الهارد ديسك قبل نسخ المجلد لحمايتك من حدوث أي Corrupt في ملفات الخريطة.
